# Asset Penpot

- `rme-rawat-jalan-blueprint.svg` adalah papan awal journey dan workspace RME.
- `rme-gigi-akreditasi-extension.svg` adalah papan ekstensi konsultasi gigi,
  odontogram, dan pusat bukti akreditasi.

Keduanya berukuran 3200×1800 px dan sengaja dibuat tanpa font atau gambar
eksternal. Import ke Penpot, lalu gunakan groups bernama `Page-*` sebagai dasar
pemisahan frame/page.

SVG ini adalah wireframe, bukan desain final. Sumber keputusan domain tetap
berada satu tingkat di atas folder ini.
